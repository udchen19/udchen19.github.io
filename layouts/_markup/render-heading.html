{{- /* Hugo's default heading, with one change for content that uses a level-1 heading ("# English Version" in the Books post): the page title is the page's only

, so that heading renders as

and every heading after it one level lower, keeping it as their parent; headings before it keep their level (Astra review, rounds 1 and 2). Pages without a level-1 heading are unchanged. */ -}} {{- $level := .Level -}} {{- $raw := .Page.RawContent -}} {{- if findRE `(?m)^# ` $raw 1 -}} {{- $before := index (split (printf "\n%s" $raw) "\n# ") 0 -}} {{- $n := len (findRE `(?m)^#{1,6} ` $before) -}} {{- if ge .Ordinal $n }}{{ $level = int (math.Min 6 (add .Level 1)) }}{{ end -}} {{- end -}} {{ .Text }} {{- /**/ -}}
